# CN2 International LLC

A completely redesigned Create React App website for CN2 International LLC, an international sanitary ware supplier sourcing across China and Europe for European markets.

## Stack
- React + Create React App
- JavaScript
- React Router
- React Helmet Async
- React Icons

## Run locally
```bash
npm install
npm start
```

## Production build
```bash
npm run build
```
